# ClearML Report Instructions

The course instruction requires the final report to be created in ClearML Reports only.

Mandatory points:

- build the final report inside ClearML Reports;
- add all charts through ClearML Embed;
- do not use screenshots of charts;
- export the final report to PDF;
- save the exported file in this repository as `docs/report.pdf`.

What to include in the report:

- project goal and problem statement;
- dataset description;
- preprocessing and AST tokenization pipeline;
- model architecture and training setup;
- main training curves from ClearML;
- final validation metrics;
- several qualitative code-completion examples;
- conclusions and limitations.

Before the final commit, verify that the exact file path is:

`docs/report.pdf`
