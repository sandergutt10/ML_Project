# Submission Checklist

Use this file as a final pass before uploading the repository for the course defense.

- [ ] Repository name and description are filled in GitHub settings.
- [ ] `README.md` contains project description, installation steps, run commands, and final results.
- [ ] `docs/report.pdf` is exported from ClearML Reports and added to the repository.
- [ ] ClearML charts inside the report were added through ClearML Embed, not screenshots.
- [ ] `docs/task_journal.md` is fully completed for the whole semester.
- [ ] A valid checkpoint is available locally for demonstration during the defense.
- [ ] `python tests.py` was run on the final checkpoint.
- [ ] `streamlit run frontend/app.py` starts correctly with the final checkpoint.
- [ ] During the defense you can explain the dataset, tokenizer, model, training loop, and inference pipeline.
